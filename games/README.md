# Game profiles

Each folder holds one PlayStation 2 game's port: recompiler configuration, native handlers for that game, and the scripts that generate and build it from **your own disc**. No game content (disc image, executable, data or generated code) is stored here.

To play one, use the launcher: see [How to play](../README.md#how-to-play-a-game).
